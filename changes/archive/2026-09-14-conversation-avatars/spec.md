# Spec: Conversation Avatars

## 功能需求

| ID | 需求 | 验收标准 |
|---|---|---|
| F1 | 用户资料支持头像 URL | Customer、Agent、Admin/Owner 均可在“我的资料/设置”中查看和编辑头像 URL |
| F2 | 用户头像持久化 | 保存后写入用户资料，刷新页面、重新登录、工单响应中仍返回头像 URL |
| F3 | 通用用户头像展示 | 侧边栏用户菜单、工单列表客户/负责人列、工单时间线消息和审计事件显示用户头像 |
| F4 | 在线咨询头像展示 | 在线咨询中客户消息显示当前用户头像；AI 回复显示固定 AI Agent 头像 |
| F5 | 兜底行为 | 用户未设置头像或图片加载失败时，显示姓名/邮箱首字母；AI 头像不可用时显示 `AI` |

## 场景

### S1: 用户设置头像

Given 任意已登录角色进入设置页  
When 输入合法头像 URL 并保存  
Then 接口返回该 `avatar_url`，前端资料区和侧边栏展示该头像

### S2: 工单消息展示头像

Given 工单消息或审计事件包含 author/actor  
When author/actor 有 `avatar_url`  
Then 时间线节点显示对应头像图片；加载失败时显示首字母

### S3: 在线咨询展示头像

Given Customer 打开在线咨询并发送消息  
When 消息列表渲染用户消息和 AI 回复  
Then 用户气泡旁显示客户头像，AI 气泡旁显示 AI Agent 头像

## 边界约束

- `avatar_url` 是可选字符串，空字符串按未设置处理。
- 第一版只接受 `http://` 或 `https://` URL。
- 头像 URL 属于用户公开资料，可出现在工单 requester、assignee、author、actor 摘要中。
- 前端不得因为头像加载失败阻断消息或工单渲染。
- 本需求不改变角色权限和工单可见范围。

## 任务拆分

- 数据模型：为用户表、用户 schema 和工单 UserSummary 增加 `avatar_url`。
- 用户资料：设置页支持编辑头像 URL，并在侧边栏用户菜单展示头像。
- 消息渲染：工单时间线、工单列表用户列、在线咨询面板展示头像。
- 验证归档：构建、类型检查、迁移检查、健康检查，通过后归档到系统规格。
