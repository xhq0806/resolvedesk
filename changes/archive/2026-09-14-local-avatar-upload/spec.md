# Spec: Local Avatar Upload

## 功能需求

| ID | 需求 | 验收标准 |
|---|---|---|
| F1 | 资料页本地上传头像 | 任意登录角色可在资料页选择本地图片上传头像，不再显示手填头像 URL 输入框 |
| F2 | 后端安全校验 | 仅接受 PNG、JPG/JPEG、WebP 图片；超出大小限制或内容签名不匹配时拒绝 |
| F3 | 头像本地存储和读取 | 上传成功后头像保存到服务端本地目录，`avatar_url` 返回系统生成的读取地址 |
| F4 | 清除头像 | 用户可清除自己的头像，清除后响应中的 `avatar_url` 为 `null`，前端回退首字母 |
| F5 | 展示兼容 | 侧边栏、工单列表、工单时间线、在线咨询继续使用 `avatar_url` 展示头像 |

## 场景

### S1: 上传头像

Given 用户登录并进入资料页  
When 选择合法本地图片并上传  
Then 后端保存图片文件，返回新的 `avatar_url`，前端头像预览和侧边栏更新

### S2: 非法头像

Given 用户登录并进入资料页  
When 上传非图片、伪造 MIME 或超大图片  
Then 后端返回校验错误，不修改当前头像

### S3: 清除头像

Given 用户已有头像  
When 点击清除头像  
Then 后端删除本地头像文件并清空 `avatar_url`，所有展示位置使用首字母兜底

## 边界约束

- 头像图片读取地址是公开用户资料资源，不要求 Bearer token。
- 上传和清除头像必须要求登录。
- 本需求不改变用户角色、Workspace 权限和工单可见范围。
- 旧外链 URL 输入不再作为产品入口。

## 任务拆分

- 后端新增头像上传、删除、公开读取接口与本地存储校验。
- 前端新增头像上传 API 封装，资料页改为文件上传和清除按钮。
- 更新系统文档、精简 spec、构建与接口验证，完成归档。
